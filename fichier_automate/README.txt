Format recommandé  :

L1 : nombre de symboles de l’alphabet (ε exclu)
L2 : nombre d’états
L3 : nombre d’états initiaux suivi de leur liste
L4 : nombre d’états terminaux suivi de leur liste
L5 : nombre de transitions
L6 et suivants : transitions sous la forme <état_depart><symbole><état_arrivée>
Les automates #31 à #35 utilisent le symbole ε.
L’automate #41 inclut l’état P tel qu’il apparaît dans le document fourni.
Pour le projet, il est recommandé de créer un fichier par automate, nommés de automate_1.txt à automate_44.txt.
